# 简体中文与语言切换

Wave 支持简体中文和英文界面，并可跟随操作系统语言自动选择。

## 切换语言

1. 点击窗口右侧工具栏底部的齿轮图标。
2. 选择 **设置**。
3. 打开 **常规**，保持在 **可视化** 标签。
4. 在 **界面语言** 中选择 **跟随系统**、**简体中文** 或 **English**。

语言会立即切换并保存到 `settings.json`：

```json
{
  "app:language": "zh-CN"
}
```

可用值为：

- `auto`：跟随操作系统语言。
- `zh-CN`：简体中文。
- `en-US`：英文。

Wave 只翻译应用界面，不会修改终端输出、文件内容、命令、路径或 AI 回答。你仍然可以直接使用中文与 DeepSeek、Kimi 等模型交流。
